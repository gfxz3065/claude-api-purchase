## Claude API 到底怎么收费？

Claude API 不是“买一个月无限使用”，而是典型的按量计费。Anthropic 官方按照输入 Token 和输出 Token 分别计算费用，不同模型的价格也不同。官方价格页面会按每百万 Token 展示输入、输出、缓存和批处理等费用。

简单理解：

- 你发送给模型的内容属于输入；
- 模型返回给你的内容属于输出；
- 输入上下文越长，输入费用通常越高；
- 回复越长，输出费用通常越高；
- 某些模型的输出价格明显高于输入价格；
- Prompt caching、Batch API 等功能可能采用不同计费规则。

举个不涉及具体账单的例子：一个普通问答请求可能只消耗少量 Token，但如果你每次都把完整项目代码、长篇文档和历史对话一起发过去，单次请求的输入量就会迅速增加。很多人以为“只是问了一个问题”，实际上 API 账单计算的是请求中包含的全部 Token。

Anthropic 官方说明，API 额度也可以用于 API、Workbench 和 Claude Code；当余额耗尽后，相关调用会停止，直到账户添加新的额度。

- Session Key 或 Cookie 已失效；

- 账号绑定的支付信息导致状态异常；
- 提交的账号与购买账号不一致；

WildAI 文档建议重新登录后重新获取完整凭证，并确认账号状态正常。如果同一个错误反复出现，继续重复提交通常不会解决问题，保留错误截图并联系平台客服更有效。

## 用 API 前，建议先做这几项设置

充值后，不要马上把额度投入高频任务。先完成基本的用量控制。

### 设置预算提醒

在 Claude Console 的 Billing 页面查看余额和用量。Anthropic 官方支持预付额度，并提供自动充值相关设置；是否启用自动补充，应根据项目预算决定。

### 从低成本模型开始测试

如果任务只是分类、摘要、信息提取或简单改写，不一定需要最贵的模型。先用适合任务的模型跑一批样本，再比较质量和消耗。

### 限制最大输出长度

很多 API 成本来自过长回复。对结构化提取、分类和简短问答，可以设置合理的最大输出 Token，避免模型生成超出实际需求的大段内容。

### 不要每次发送无关历史

上下文越长，输入 Token 越多。保留真正有用的对话内容，删除重复说明、无关代码和已经确定的背景信息，通常比单纯购买更大额度更有效。

### 给不同任务分开统计

开发测试、批量内容处理和正式用户请求最好分开记录。这样可以看出哪类调用最耗余额，也能判断 $20 是否足够，还是应该转向 $100 档位。

## 常见问题

### Claude API $20 充值是订阅一个月吗？

不是。它是账户余额额度，不是按月订阅。余额会随着 API、Workbench 或其他支持该额度的服务使用而扣减。

### 买 Claude Pro 后能直接调用 API 吗？

不能直接这样理解。Claude Pro 和 API Console 是独立产品，Pro 订阅不会自动包含 API 余额。

### $100 方案是不是比 $20 方案模型更强？

不是。两者主要是充值金额不同，不是模型档位不同。实际能使用哪些模型，取决于 Claude API 账户权限和官方当前提供的模型。

### API 余额用完会怎样？

当余额耗尽后，API 调用和相关使用会受到影响，需要先添加新的额度。建议提前查看 Billing 页面，不要等到生产任务运行中途才发现余额为零。

### 可以一天充值多次吗？

WildAI 的 Claude API 问题说明中写明，已经取消旧的“每天只能充值一次”限制，当前可以根据页面流程提交多笔充值订单。但如果前一笔仍在处理中，最好先确认状态，避免重复下单造成排查困难。
